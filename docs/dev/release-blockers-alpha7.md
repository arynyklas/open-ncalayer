# Блокеры выпуска 0.1.0-alpha.7

Одна таблица: всё, что открыто на момент написания. Источники: ledger плана платформы (`progress.md` в рабочем дереве), [`manual-plugins-status.md`](manual-plugins-status.md), [`platform-acceptance.md`](platform-acceptance.md), [`platform-interop.md`](platform-interop.md), [`winget.md`](winget.md), код дерева. Порядок выпуска — [`release-runbook-alpha7.md`](release-runbook-alpha7.md).

Решение владельца: **alpha.7 заблокирован**, пока не выполнены все ручные проверки и матрица ВМ. «Статус» ниже:

- **БЛОКИРУЕТ** — без закрытия alpha.7 не выходит;
- **ВНЕ alpha.7** — решено не делать в этом выпуске, документировано;
- **ПРИНЯТО** — владелец принял как известное ограничение (решение записано);
- **В РАБОТЕ / ОЖИДАЕТ** — исполнитель назван, итог ещё не в этом дереве.

Состояние на дату написания; перед выпуском сверить с ledger. Ledger обновляется независимо от этого файла и может опережать его. Документ `platform-acceptance.md` в этом дереве говорит, что 1 ГиБ-ворота «не запускались» — это отстаёт от ledger (там записаны три прогона, см. строку 3): считать ledger более свежим источником.

- **Q3.** Какие пункты из списка (c) раздела 3 `manual-checks-runbook.md` вы принимаете как «известное ограничение» для alpha, а какие блокируют?
