# Токены (экспериментально)

OpenNCALayer читает ключи и подписывает на носителях шести семейств, которые знает Kalkan: Kaztoken, удостоверение личности РК, eToken PRO 72K, eToken 5110, JaCarta и AKey. Поддержка экспериментальная: каждый драйвер проверен только на программном эмуляторе своего носителя, на настоящих носителях — ещё нет. Поэтому она **выключена по умолчанию**.

- **Как включить:** «Настройки…» → «Токены и удостоверение личности (экспериментально)». Флажок действует сразу, без перезапуска: уже открытые ключи носителей (у плагина — до `keys_release`) после выключения не подписывают.
- **Что работает:** носители в окне хранилища (считыватель, кнопка «Обновить», PIN-код и число оставшихся попыток), подпись CMS, CAdES и XML ключом носителя, `getActiveTokens`, `loadSlotList`, `browseKeyStore`, `getPublicPartInfo`, ключи носителей в плагинах. Подпись носителя проверяется сертификатом, прежде чем уйти сайту.
- **Чего нет:** записи на носитель — создания ключей, записи сертификата, удаления ключа, форматирования и смены PIN-кода. Такие вызовы при подключённом носителе отвечают общим кодом ошибки оригинала и ничего не отправляют носителю.
- **PIN от страницы:** PIN, который плагин получил от страницы, носителю уходит только после окна согласия с сайтом, носителем и числом оставшихся попыток — один раз на сайт и считыватель в сессии, перед каждым PIN при двух попытках и меньше и снова после неверного PIN. Без согласия носителю не отправляется ничего, так что сайт не может потратить попытки или заблокировать носитель без вашего щелчка.
- **Что нужно:** Windows — служба «Смарт-карта»; macOS — ничего сверх системы; Linux — `pcscd` и драйвер USB-считывателей `ccid` (Debian и Ubuntu: `sudo apt install pcscd`; Arch: `sudo pacman -S pcsclite ccid` и `sudo systemctl enable --now pcscd.socket`). Без службы OpenNCALayer работает как обычно, а окно хранилища пишет «Служба смарт-карт недоступна».

> **Внимание.** Как и оригинальный NCALayer, OpenNCALayer отвечает на `getActiveTokens`, `loadSlotList` и `getPublicPartInfo` без запроса пользователю. Пока поддержка токенов включена, **любой открытый сайт может узнать, какие носители подключены, и прочитать ИИН и ФИО владельца вставленного удостоверения личности.** В Linux имена считывателей, которые возвращают `loadSlotList` и `keys_terminals` плагинов, могут содержать серийный номер USB-носителя (его добавляет к имени `pcscd`), а по нему узнаётся конкретный носитель. Включайте её только тогда, когда носитель действительно нужен.

Устройство, таблица семейств, PIN-код, эмулятор и трассировка `ONCL_TOKEN_TRACE=1` для сообщений о проблемах — [`docs/design/tokens.md`](../design/tokens.md).
