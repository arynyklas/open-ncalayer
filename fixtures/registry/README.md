# Фикстуры сайта проекта

Синтетические входы `cargo xtask registry build`: вымышленные порты, индексы обновлений, список релизов и данные ветки `upstream`. Настоящих данных оригинала здесь нет; реальное имя есть только у бандла ядра `kz.gov.pki.kalkan.xmldsig`, который уже перечислен в коде (`oncl_accessory::bundles`). Лицензия репозитория (Apache-2.0).

| Путь | Что |
|---|---|
| `plugins/alpha/` | порт в `stable` и `beta`; у оригинала та же версия (`same`) |
| `plugins/gamma/` | порт без индексов; у оригинала другая версия (`changed`) |
| `plugins/hostile/` | порт только в `beta`, бандла нет в фактах (`removed`); все текстовые поля — враждебная разметка и синтаксис шаблонов |
| `updates/v1/{stable,beta}.json` | индексы каналов: отозванные версии, раскатка, плагины на релизе `plugins-20261101`; без подписей |
| `releases.jsonl` | список релизов в формате шага `gh api` workflow: `v0.2.0` со всеми файлами, пререлиз `v0.3.0-beta.1` без файлов macOS, черновик `v0.3.0-beta.2`, тег плагинов |
| `upstream/index.json`, `upstream/latest/facts.json` | история (первое наблюдение и изменение, у изменения недопустимый `path`) и факты манифеста: порты `alpha` и `gamma`, бандл ядра с версией не как у нас, бандл без порта; заметки с враждебным текстом |

Файлы правятся руками вместе с тестами `xtask::registry` и `xtask/tests/registry_site.rs`, которые на них опираются.
